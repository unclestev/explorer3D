- Lights that must look bright at night can't be map shapes (the map's night light dims every fill-extrusion); put a glow in the car-layer three.js `scene` like buildings.js `lampGlow`. Night-only shapes (light washes on walls) go in their own layer shown only at night, so they never show by day (addendum 18).

With terrain on, `queryRenderedFeatures` at a screen point returns nothing — use `map.unproject` + point-in-polygon on `querySourceFeatures`. ## Pitfalls learned the hard way
- Never put a `//` comment in the middle of a one-line statement list (it silently commented out `camera.setViewOffset` once, and broke two files' syntax; again in traughber.js's one-line `window.TRJ={…}` 2026-11-24). Use `/* */`.
- buildings.js has its own local `const TRJ` (Traughber colours): reach traughber.js there only as `window.TRJ`.
- OpenFreeMap shares one building id across a whole subdivision (Traughber's school + ~140 houses): never pick buildings "near a point" by id or by a low area cut — houses/townhouse rows (~1000 m²) sneak in (addendum 24).
- Anything added to the traffic.js OCC blockers must be a kind that the "building you're in" test (`mine()`) drops, or it hides the indoor room's own walls (addendum 24).
- three.js r128 skips an object only if `visible === false` exactly — `visible=0` still draws (the backup camera stuck on screen).
- With 3D terrain or in the cockpit, avoid `queryRenderedFeatures` (GPU read-back, ~10 ms each); use `QGEO()` / `geoBlocks` / `geoRoads`.
- With 3D terrain, MapLibre lifts each fill-extrusion feature by the ground height at its centroid. OpenFreeMap groups whole subdivisions into one building feature, so anything stacked on a building (roofs, windows) must stand on a per-building feature, not on the vector building (addendum 14).
- With 3D terrain every ground layer is drawn once per terrain tile: layer count matters more than triangle count. Invisible (opacity ~0) layers still cost full price — hide them with visibility none (addendum 17).
- `querySourceFeatures` features decode their geometry on every `.geometry` read — read it once.
- The map style draws mapped sidewalks (class path, subclass footway) as a white dashed line; that is what looks like "spaced out slabs". Restyle the layer, don't hunt for our own sidewalk code first (addendum 15).
- Per-frame checks that walk building footprints are expensive in dense cities (downtown LA): the depth-only building blockers (traffic.js `OCC`) already hide car-layer things — don't add per-object sight-line walks where they cover.
- Heavy rebuilds must be sliced over frames (see `OCC.job`, parking.js `stallJob`), not done in one go.
- Overpass mirrors can be very slow and refuse parallel questions; `ovFetch` queues them one at a time. Cap every Overpass wait (~18 s) where a user is waiting and have a fallback.
- `typeof x` on a `let` still in its temporal dead zone throws — only reference module `let`s from callbacks that run after load.
- Button index 0 is falsy: test bindings with `b.b!=null`, never `!b.b`.
- `WALK.inside` is always an object; "inside a building" is `WALK.inside.rec`.
- Cockpit glass is transparent with depthWrite off: anything that must hide the glass's frit/dots (pillars) has to draw after it (transparent + higher renderOrder).
- traffic.js `drive(a,dt,px,py,pv,ph)`: speed comes before heading.
