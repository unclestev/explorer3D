# Addendum 16 — snowmen in front yards (2026-11-23)

Owner asked: "when it is snowing and snow accumulates more than 3 inches show snowmen randomly in peoples front yards". Local branch `snowmen` (commit 016ddf8, also pushed as test branch `claude-test-snowmen`), not on main yet. Files: new js/enh/snowmen.js ?v=1 (loaded right after buildings.js), buildings.js ?v=15, README line.

- buildings.js: `streetDir()` now also returns `.d` (metres to the road). New `yardSpot(P,front,sd,free,seed,kx,ky)` picks a spot between the street-side wall and the road (yard = d/(n·sd) − wall − 6.5 m, needs ≥ 3.5 m; front wall must face the street, n·sd ≥ .6), clear of the garage and front door (`free()` / busy spans, ±0.9 m) and ≥ 2.8 m from any mapped driveway (`DRIVES`). Stored on the house record as `bld.yard = {x,y,fx,fy}` (local metres + facing), so it's on every entry of `ROOFS.doorsNear()`. About 60 of 150 houses near Heartland Dr get a spot.
- snowmen.js: layer `snowmen` (fill-extrusion, geojson source `snowmen`, props c/b/h, inserted before `wall-3d`, re-added on styledata). Every 1 s: shown when `SNOWCOVER.inches > 3` (hides below 2.5 — hysteresis) and not in glider. Per house `hash(seed,1) < .28` gets one; seed is the same house seed as buildings.js, so the same yards always have them. Each: three balls as stacked slices (6/5/5), coal eyes/smile/buttons, carrot nose, two-segment stick arms with twigs, scarf (neck ring + hanging end), top hat (60%) or knit cap with pompom; size .85–1.15; 18% get a small one beside. ~55 features each. Data only re-sent when the set of houses changes.
- Testing: `SNOWCOVER.set(1,8)` (it melts while not snowing — re-set it in a 500 ms interval for screenshots), `SNOWMEN.force(true|null)`, `SNOWMEN.count`. Heading is `S.hdg` (not `S.h`). Checked live on githack at 41.6489,-88.4430: 8–12 snowmen, look right up close, gone at 2 in, back at 5 in, no errors.
