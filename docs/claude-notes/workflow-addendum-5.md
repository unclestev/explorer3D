- ?v=84 fix: the corner shadows never switched on when parked. The job was stepped inside `update()`, which only runs when game.js actually redraws (`camMoved||settling||live||trafficMoving…`) — parked and still that's a few frames a second or none, so the generator stalled. It's now stepped from a `FRAME_HOOKS` hook (`cockpitAO`, runs every frame in car mode), which returns true on the finishing frame to force one redraw. **Pitfall:** anything that must progress while parked (sliced jobs, timers) belongs in a frame hook, not in `COCKPIT.render`/`update()`.

## Music follows the engine (2026-11-22 18:3x, committed locally as 0f47487, music.js ?v=3, NOT pushed until the owner says push)
- Owner: music must turn off when the engine is turned off, and on again with it — on the same station.
- `music.js` polls `IGN.state` every 250 ms (a timer, so it works parked). Engine "on" = `IGN.state==='on'` only: stop / off / crank are silent (radio doesn't play over the starter). Cutting: pauses and remembers whether it was playing (`resume`). Engine caught: live radio reloads the stream (`play(now)`), a song continues (`au.play()`). Picking a station or song while off is remembered (toast "Turn the engine on to listen") and starts when the engine is on; the ⏯ button does nothing while off; ⏹ or a manual pause before engine-off means it stays off. Changing car / mode resets IGN to 'on', so music resumes then too.
- Tested live in the browser pane with a muted Audio (fetched the live music.js, applied the same edits, flipped `IGN.state` through stop/off/crank/on): all cases passed.
